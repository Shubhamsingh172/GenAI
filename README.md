# 📌 Mini Projects

## ✅ Resume Parser

A Resume Parsing application that:

- Extracts information from PDF and DOCX resumes
- Parses candidate details using an LLM
- Extracts:
  - Skills
  - Education
  - Experience
  - Projects
- Matches candidate information against a Job Description
- Calculates Resume Match Score
